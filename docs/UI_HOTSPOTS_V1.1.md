# Stormland FR V1.1 — zones interactives

Skin exact : `assets/Stormland_install.png` — **1200 × 675 px**.

Aucun cadre de survol ou de sélection n'est dessiné sur les boutons du skin. Les contours visibles appartiennent uniquement à l'image fournie.

Zones cliquables natives :

- Fermer : `x=1120..1199`, `y=0..81`
- Parcourir : `x=620..764`, `y=360..424`
- Installer la traduction : `x=73..431`, `y=430..522`
- Désinstaller la traduction : `x=435..796`, `y=430..522`
- Original par défaut : `x=82..318`, `y=540..615`
- Custom : de face : `x=324..571`, `y=538..616`
- À propos : `x=720..894`, `y=570..641`

Sémantique :

- **Original par défaut** = emplacement natif Stormland, module de texte à droite.
- **Custom : de face** = déplacement Stormland FR validé (HUD Custom V0.0.81 historique), face au joueur et plus bas.
- Traduction et placement du module de texte sont indépendants.
